# Read Anywhere

A Mac menu-bar app that reads any selected text aloud — in a terminal, a
browser, an editor, anywhere — with natural neural voices.

## Download

**[Download Read Anywhere (.dmg)](https://github.com/tamirlavystudio/read-anywhere-releases/releases/latest/download/ReadAnywhere.dmg)** — macOS 14 or later, Apple Silicon and Intel.

1. Open the downloaded `ReadAnywhere.dmg`.
2. Drag **Read Anywhere** onto the **Applications** folder.
3. Launch it from Applications. It lives in the menu bar (no Dock icon).
4. When asked, turn on **Read Anywhere** in
   **System Settings → Privacy & Security → Accessibility**. That lets it copy
   your selection; without it, the shortcut just beeps.

Then select some text and press **⌃⌥R**.

## Updates

Read Anywhere checks for updates once a day and shows an **Install Update**
button when a new version is out. You can also check any time from the menu
bar icon → **Check for Updates…**.

This repository only hosts the installers and the update feed
(`appcast.xml`).
